# 论文公开材料包说明

## 已整理的内容

- 当前论文使用的 Fig1–4 PDF，以及 Fig5–14 的 EPS 和现有 PDF 显示版本。
- 表1的全部12项实验参数，整理为可直接读取的 CSV，原文数值和单位保持不变。
- 论文中报告的软件环境、硬件配置和实验比较设置，整理为 JSON。
- 图号、图注、文件路径和校验值的对应表。
- 原文实验设置摘录、数据字典，以及离线文件完整性检查脚本。

## 材料边界

这是“当前电脑可获得的论文支撑材料”，不是完整原始实验数据集。
另一台电脑中的数值结果、逐次实验日志和实验实现代码不在此次整理范围内。
没有用图片反推数值，也没有生成、补造或插值任何实验结果。

图文件可以查看论文已经展示的曲线，但不能代替曲线对应的数值表，
也不能单独支持重新运行实验。`metadata/materials_not_included.csv`
记录了这些边界，不要求你现在从另一台电脑取文件。

## Fig1–4 的来源

已经记录你的确认：当前 Fig1–4 均为你使用 Microsoft Visio 手工重画，
没有使用生成式 AI 生成图形内容，因此不为这四幅图添加生成式 AI 图形披露。
本地较早的 `.vsdx` 尚未确认与最新版 PDF 一致，未混入公开目录。

## 公开前的处理

1. 文件夹和同名 ZIP 的内容相同，可以作为一个材料包上传。
2. 上传记录应称为“supporting materials”，不要称为“完整原始数据及代码”。
3. 许可证由你或团队根据权属选择，本次没有擅自设置开放许可证。
4. 获得仓库永久链接或 DOI 后，再把真实链接交给我更新数据可用性声明与引用。
5. 仅公开现有图文件和参数，并不等于已经公开支撑所有实验结论的数值数据；
   后续声明必须准确说明仓库的实际内容。

## 检查方法

在本文件夹中运行：

```text
python scripts/verify_release.py
```

该脚本只检查文件完整性、图号对应和表1转录，不重新运行实验。

## 参数注意事项

表1中的 `Gcycle/s`、`32MB`、`200GB`，以及正文中的 `10MB`，
均按原文保留。本次不擅自解释、改写或修正这些单位，也未修改论文结果。
